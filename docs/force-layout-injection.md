# 클러스터 → 개별 노드 전환 시 초기 좌표 주입 로직

## 코드 위치

`apps/frontend/src/components/GraphRenderer.tsx` — LOD useEffect 내 `needsLayout` 분기

## 해결하는 문제

클러스터가 해제되면 멤버 노드들이 모두 동일 좌표(클러스터 중심)에 겹쳐 배치된다.
`render()`로 force-layout을 돌리면 랜덤 초기 위치에서 시작하므로 매번 다른 결과가 나온다.

**목표**: 클러스터 위치 근처에서 결정적(deterministic)으로 분산 배치한 뒤 force-layout을 실행. 이미 안정 상태에 가까운 초기 좌표에서 시작하므로 빨리 수렴하고, 이전 배치와 유사한 결과를 얻는다.

---

## 핵심 개념 1: G6의 `getData()` 반환 구조

```typescript
const currentData = graph.getData();
// 반환 형태:
// {
//   nodes: [{ id: 'RF-01', style: { x: 150, y: 200, ... }, data: { ... } }, ...],
//   edges: [{ id: 'e1', source: 'RF-01', target: 'F-01', ... }, ...]
// }
```

G6 v5에서 `getData()`는 현재 그래프에 렌더링된 노드/엣지의 **내부 상태**를 반환한다.
중요한 점:
- `node.style.x` / `node.style.y` — 현재 캔버스 상의 픽셀 좌표
- `node.id` — 노드 식별자
- `node.data` — 사용자가 설정한 커스텀 데이터 (nodeType, country 등)

이 구조를 알아야 "현재 위치를 캡처"할 수 있다.

---

## 핵심 개념 2: `style.x/y` 주입 → force-layout 초기값

G6의 force-layout(`d3-force`)은 시뮬레이션 시작 시 각 노드의 초기 위치를 결정한다.

- `style.x/y`가 **없으면**: 랜덤 위치에서 시작 → 매번 다른 결과
- `style.x/y`가 **있으면**: 해당 좌표를 초기값으로 사용 → 결과가 일관됨

```typescript
// setData 시 style에 좌표를 포함시키면 force의 시작점이 된다
nodeAny.style = { x: 150, y: 200 };
graph.setData(data);
graph.render(); // force가 (150, 200) 근처에서 시작
```

이 동작 덕분에 클러스터 위치 근처에서 force를 시작할 수 있다.
force는 "이미 거의 맞는 위치"에서 시작하므로 최종 결과가 이전 배치와 유사하게 수렴한다.

## 핵심 개념 3: 황금각(2.4 rad) 분산

### 문제

클러스터에서 풀려난 멤버 노드 N개를 한 점 근처에 배치할 때, 겹치지 않게 분산해야 한다.

### 왜 황금각인가

황금각(Golden Angle) = 약 2.399... rad ≈ 137.5°

해바라기 씨앗 배치에서 유래한 수학적 분산 패턴이다.
매 노드마다 이전 노드에서 2.4 radian 회전하면, **어떤 수의 노드든** 균일하게 분산된다.

```
노드 0: angle = 0 * 2.4 = 0.0 rad
노드 1: angle = 1 * 2.4 = 2.4 rad
노드 2: angle = 2 * 2.4 = 4.8 rad (= 4.8 - 2π ≈ 1.52 rad)
노드 3: angle = 3 * 2.4 = 7.2 rad (= 7.2 - 2π ≈ 0.92 rad)
...
```

### 단순 균등 분할 vs 황금각

| 방법 | 3개 노드 | 7개 노드 | 14개 노드 |
|------|----------|----------|-----------|
| 균등 분할 (360/N) | 잘 분산됨 | 잘 분산됨 | 잘 분산됨 |
| 황금각 | 잘 분산됨 | 잘 분산됨 | 잘 분산됨 |

둘 다 비슷하지만, 황금각의 장점:
- **N이 미리 정해지지 않아도** 됨 (국가별 멤버 수가 다름)
- 노드를 하나씩 추가해도 기존 배치를 바꾸지 않음
- 2π의 무리수 배수라서 어떤 N에서도 각도 겹침이 없음

### 반지름 변조

```typescript
const radius = 30 + (i % 3) * 20; // 30, 50, 70px 반복
```

같은 각도 근처에 겹치는 것을 추가 방지. 나선형 패턴을 만든다.

## 전체 코드 흐름

```
1. 현재 그래프에서 모든 노드/클러스터의 (x, y) 캡처
       │
       ▼
2. 새 데이터(개별 노드)에 대해:
   ├── 이전에 존재했던 노드 → 이전 좌표 유지
   └── 클러스터에서 풀려난 노드 → 해당 국가 클러스터 위치 + 황금각 오프셋
       │
       ▼
3. graph.setData(data)  — style.x/y 포함
       │
       ▼
4. graph.render()  — force-layout이 주입된 좌표에서 시작
       │
       ▼
5. 시뮬레이션 수렴 (노드가 클러스터 근처에서 약간만 이동)
```

## 결과

- 전환 전후 배치가 크게 달라지지 않음
- 사용자가 "방금 있던 자리" 근처에서 노드가 펼쳐지는 느낌
- 결정적 (같은 데이터 → 같은 초기 배치 → 유사한 최종 배치)
