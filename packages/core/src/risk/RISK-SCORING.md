# 리스크 점수 산정 방식

## 개요

리튬(HS 2825.20) 공급망의 노드와 엣지에 대한 리스크 점수를 정량적으로 산출하는 방법을 정의한다.  
최종 점수는 모두 **0-100 스케일**로 정규화되며, 높을수록 리스크가 크다.

---

## 1. 노드 리스크 (Node Risk)

공급망 노드(Resource, Mine, Refinery, Factory)의 리스크를 2가지 팩터로 산출한다.

### 팩터 구성

| 팩터 | 카테고리 | 원시 스케일 | 정규화 방식 | 기본 가중치 |
|------|----------|------------|------------|------------|
| HHI (공급 집중도) | `supply_concentration` | 0 ~ 10,000 | `hhi / 10000 × 100` | 0.6 |
| WGI (지정학적 안정성) | `geopolitical` | 0 ~ 100 | `100 - wgi` (반전) | 0.4 |

### 계산 공식

```
NodeRiskScore = (HHI_weight × normalizedHHI) + (WGI_weight × normalizedWGI)
             = 0.6 × (hhi / 10000 × 100) + 0.4 × (100 - wgi)
```

### HHI (허핀달-허쉬만 지수)

- **의미**: 특정 노드에 대한 인바운드 공급원 집중도
- **산출 방식**: 동적 계산 — 해당 노드로 유입되는 엣지의 volume 비중으로 자동 산출
- **공식**: `HHI(X) = Σ (volume_i / total_inbound_volume × 100)²`
- **범위**: 0 (완전 분산) ~ 10,000 (단일 공급원 독점)
- **해석**: 
  - 0~1,500: 저집중 (경쟁적)
  - 1,500~2,500: 중간 집중
  - 2,500 이상: 고집중 (독점적)
- **정규화**: 선형 변환 `hhi / 10000 × 100`
- **클램핑**: 0 미만 → 0, 10,000 초과 → 10,000
- **인바운드 엣지 없는 노드**: HHI = 0 (Resource, volume 없는 Supply 엣지만 있는 Mine)
- **구현**: `computeNodeHHI(nodeId, inboundEdges)` 함수

### WGI (세계 거버넌스 지표)

- **출처**: World Bank Worldwide Governance Indicators (2025 개정 방법론)
- **구성**: politicalStability + regulatoryQuality 복합 점수
- **범위**: 0 (최악 거버넌스) ~ 100 (최우수 거버넌스)
- **정규화**: 반전 `100 - wgi` (높은 거버넌스 = 낮은 리스크)
- **클램핑**: 0 미만 → 0, 100 초과 → 100
- **국가별 참고값** (wgi-scores.json):

| 국가 | WGI 종합 | 거버넌스 리스크 (100 - composite) |
|------|---------|-------------------------------|
| 일본 | 80.55 | 19.45 |
| 한국 | 73.84 | 26.17 |
| 미국 | 70.23 | 29.77 |
| 칠레 | 67.58 | 32.43 |
| 중국 | 58.51 | 41.49 |

### 계산 예시

**F-04 (CATL Ningde, 중국)** — 고집중
- 인바운드: RF-01에서 50,000,000kg (62.5%), RF-02에서 30,000,000kg (37.5%)
- HHI = 62.5² + 37.5² = 3906 + 1406 = **5,313**
- WGI = 58.51 (중국) → 거버넌스 리스크 41.49
- **최종 점수 = 0.6 × (5313/10000×100) + 0.4 × 41.49 = 0.6 × 53.13 + 0.4 × 41.49 = 31.88 + 16.60 = 48.47**

**F-01 (EcoPro BM Pohang, 한국)** — 중간 집중
- 인바운드: RF-01 17.98M (29.5%), RF-02 3.73M (6.1%), RF-03 19.28M (31.6%), RF-04 20M (32.8%)
- HHI = 29.5² + 6.1² + 31.6² + 32.8² = 870 + 37 + 999 + 1076 = **~2,981**
- WGI = 73.84 (한국) → 거버넌스 리스크 26.16
- **최종 점수 = 0.6 × 29.81 + 0.4 × 26.16 = 17.89 + 10.46 = 28.35**

**F-05 (Tesla Giga Nevada, 미국)** — 단일 공급원
- 인바운드: RF-05에서 10,699,831kg (100%)
- HHI = 100² = **10,000**
- WGI = 70.23 (미국) → 거버넌스 리스크 29.77
- **최종 점수 = 0.6 × 100 + 0.4 × 29.77 = 60 + 11.91 = 71.91**

## 2. 엣지 리스크 (Edge Risk)

공급망 엣지(Supply, Delivery 관계)의 리스크를 2가지 팩터로 산출한다.

### 팩터 구성

| 팩터 | 카테고리 | 원시 스케일 | 정규화 방식 | 기본 가중치 |
|------|----------|------------|------------|------------|
| 무역량 의존도 | `trade_volume` | 0 ~ 1 | `tradeDependency × 100` | 0.5 |
| 규제 리스크 | `regulatory` | 0 ~ 100 | 그대로 사용 (클램핑) | 0.5 |

### 계산 공식

```
EdgeRiskScore = (trade_weight × normalizedTradeDependency) + (regulatory_weight × normalizedRegulatory)
             = 0.5 × (tradeDependency × 100) + 0.5 × regulatoryRisk
```

### 무역량 의존도 (Trade Dependency)

- **의미**: 해당 엣지를 통한 공급이 전체 공급에서 차지하는 비중
- **범위**: 0 (의존 없음) ~ 1 (100% 의존)
- **정규화**: `tradeDependency × 100`
- **클램핑**: 0 미만 → 0, 1 초과 → 1

### 규제 리스크 (Regulatory Risk)

- **의미**: 해당 무역 경로에 적용되는 규제적 장벽 수준
- **포함 요소**:
  - IRA (미국 인플레이션 감축법) 준수 여부
  - 수출 규제/제한 수준
  - 관세 및 무역 장벽
- **범위**: 0 (규제 없음) ~ 100 (완전 차단)
- **클램핑**: 0 미만 → 0, 100 초과 → 100

### 계산 예시

**중국 → 한국 리튬 공급 엣지 (IRA 미준수)**
- tradeDependency = 0.8 (한국 리튬 수입의 80%가 중국산) → 정규화 80
- regulatoryRisk = 85 (IRA 미준수 + 수출 규제 가능성) 
- **최종 점수 = 0.5 × 80 + 0.5 × 85 = 40 + 42.5 = 82.5**

**칠레 → 미국 리튬 공급 엣지 (IRA 준수)**
- tradeDependency = 0.3 (미국 리튬 수입의 30%) → 정규화 30
- regulatoryRisk = 10 (FTA 체결국, IRA 준수)
- **최종 점수 = 0.5 × 30 + 0.5 × 10 = 15 + 5 = 20**

---

## 3. 공통 규칙

- 모든 최종 점수는 **0-100** 범위로 보장 (팩터 정규화 및 클램핑)
- `isHighRisk` 플래그는 별도 `flagHighRisk(scores, threshold)` 함수에서 임계값 기준으로 설정
- `computedAt`에 계산 시점 타임스탬프 기록
- 가중치 합계는 반드시 1.0 (노드: 0.6 + 0.4, 엣지: 0.5 + 0.5)
